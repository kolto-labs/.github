**Life support for the Odyssey engine.**

Tools for *Knights of the Old Republic* and *The Sith Lords*: file-format libraries, a
command-line query tool, a mod installer, a script extender and a test harness.
Project Telos, the games in your browser, is in development. You bring your own copy
of the game.

So much more is to come. Expect great things both horizontally and vertically.

Start at [kolto-labs.org](https://kolto-labs.org/). Bug reports with steps to reproduce
are the most useful thing you can send us.
